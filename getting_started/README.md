# Getting Started

Welcome! You do not need a powerful computer or years of programming experience to follow this course.

Here, you will learn by writing standard Python scripts that send simple JSON messages to an AI model. Even a tiny model running on a basic laptop is enough to understand every core concept. The answers might be brief or imperfect, and that is completely okay. The goal is to learn how scripts work, how JSON keys fit together, and how agent loops run—not to get flawless answers right away.

The default model used in the course notes (`qwen3.6:35b-a3b-65k`) is great for capable local machines, but it is not required. Any model you can run will work.

## Step-by-Step Setup

Follow these simple steps to get ready:

1. **Install Python**: Download and install [Python 3](https://www.python.org/downloads/). During installation, make sure to check the box that says **Add python.exe to PATH**.
2. **Choose a model**: Read [Pick a model that fits your machine](./01_pick_a_model.md) to find the right size for your computer.
3. **Run your model**: You can run models locally using [Ollama or LM Studio](./02_ollama_and_lmstudio.md), or connect to cloud providers with [OpenAI, Gemini, or Claude](./03_cloud_apis.md).
4. **Create your configuration file**: In your terminal from the repository root folder, copy the example environment file:

```bash
cp .env.example .env
```

```powershell
copy .env.example .env
```

Open `.env` in your text editor and uncomment the lines for the provider you want to use.

5. **Open your workspace**: Open this repository in your favorite editor, such as [Cursor, VS Code, Claude Code, Antigravity, or a terminal](./04_editors_and_terminal.md).
6. **Test your setup**: Run your [first lab](./05_first_lab.md) to confirm that Python and your model can talk to each other.
7. **Start learning**: Once your first lab prints text, dive into Chapter 00 at [`education/00_atoms/`](../education/00_atoms/).

If any step gives you an error, take your time and stay on that page until it works before moving forward.

## What Success Looks Like

When your setup is complete, you can open a terminal in this project and run:

```text
python education/00_atoms/lab1_script_posts_json.py
```

When you see a few sentences generated by the model printed to your screen, your environment is ready for Chapter 00!

> **Security Note**: Never commit your `.env` file to git, as it may contain private API keys.
