# The Core Parts of an Agent: Brain, Memory, Planning, and Tools

In agent architectures, people often describe agents using human metaphors like "brains," "memories," and "actuators." 

In practice, an agent is simply a Python process ([Chapter 13](../../education/13_one_agent/00_persona_tools_loop_state.md)) combining a system prompt, a tool registry, an execution loop ([Chapter 04](../../education/04_the_loop/00_the_react_loop.md)), and a persistence store.

Here is how those human-like concepts map directly to literal software objects:

| Metaphor | Literal Code Object |
|---|---|
| **Brain / Foundation Model** | The provider process and neural network weights ([Chapter 00](../../education/00_atoms/00_script_provider_weights.md) and [Chapter 01](../../education/01_the_call/00_the_wrapper_and_the_stream.md)). It evaluates probability distributions over tokens to produce text and `tool_calls`. It cannot execute shell commands on its own. |
| **Working (Short-Term) Memory** | The `messages` list in the current session ([Chapter 02](../../education/02_the_contract/00_messages_and_json.md) and [Chapter 07](../../education/07_the_state/00_save_the_messages.md)), constrained by the model's context window. |
| **Long-Term Memory** | External persistence stores outside the context window, such as session files (`state_store/{session_id}.json`), `facts.json`, or local vector indexes ([Chapter 09](../../education/09_agentic_memory_and_rag/01_agentic_memory.md)). |
| **Planning & Reasoning** | The iterative ReAct loop ([Chapter 04](../../education/04_the_loop/00_the_react_loop.md)), Plan-and-Solve strategies ([Chapter 11](../../education/11_planning_and_reflection/00_planning_and_reflection.md)), or deterministic DAG workflows ([Chapter 10](../../education/10_the_workflow/01_graph_workflows.md)). |
| **Self-Reflection** | A Reflexion loop ([Chapter 11 Lab 2](../../education/11_planning_and_reflection/lab2_reflexion_loop.md)) where the agent inspects an error traceback or tool output, updates its plan, and tries a new approach. |
| **Reasoning Tags (CoT)** | Hidden internal tokens (like `<think>...</think>`) generated by reasoning models and parsed cleanly by a demuxer ([Chapter 06 Lab 1](../../education/06_the_reliability/lab1_cot_demuxer.md)). |
| **Actuators / Hands** | Python functions declared in `TOOLS_SCHEMA` and executed via `TOOL_REGISTRY` ([Chapter 03](../../education/03_the_dispatcher/00_tool_dispatch.md)). |

To decide whether a feature should be a simple tool function, a persistent job, or an isolated wrapper loop, consult the [Shape Tree Guide](./04_shape_tree.md) and [When X vs Y](../decisions/01_when_x_vs_y.md).
