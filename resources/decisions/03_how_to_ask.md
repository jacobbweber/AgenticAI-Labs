# How to ask

When you lack the word, ask about the object. Do not start from a staff title or a product name.

- What file or port is this? ([00](../../education/00_atoms/00_script_provider_weights.md), [00_script_server_weights.md](./00_script_server_weights.md))
- What JSON keys go out and come back? ([00 lab2](../../education/00_atoms/lab2_read_the_json.md), [02](../../education/02_the_contract/00_messages_and_json.md), [03](../../education/03_the_dispatcher/00_tool_dispatch.md))
- Who runs the function, the script or the provider? (`tool_calls`: provider emits, script runs. [03](../../education/03_the_dispatcher/00_tool_dispatch.md), [00](./00_script_server_weights.md))
- Does this need a second `messages` list? ([14](../../education/14_two_agents/03_skill_vs_two_agents.md))
- Does this need a row that outlives the process? ([18](../../education/18_the_job/00_the_job.md))
- Does this need a recipe file? ([15 lab2](../../education/15_mcp_and_skills/lab2_skills.md))
- What shape is this (tool vs job vs wrapper vs this loop)? ([notes 04](../notes/04_shape_tree.md))

Do not ask "how do I build an observability agent." Ask "does log watch need a model, a cron that writes `jobs.json`, or a regex tool?"

Fill [01_when_x_vs_y.md](./01_when_x_vs_y.md). That is the form. The dual-name tree is [notes 04](../notes/04_shape_tree.md).
