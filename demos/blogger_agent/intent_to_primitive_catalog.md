# Intent-to-Primitive Reference Catalog & Translation Index

## 1. Overview & Purpose

This catalog bridges non-technical business requirements ("What I want the app to do") directly to exact software primitives ("What code implementation is required").

When prompting AI coding assistants (like Antigravity, Gemini, or Claude), use the **Plain English Description** or reference this table directly. This forces the AI assistant to assemble production primitives from your library instead of writing basic 1-off scripts.

## 3. How to Prompt AI Assistants Using This Catalog

When starting any new feature in a demo project, include the following directive in your initial prompt:

> *"I am building a production agent application. Instead of writing basic 1-off scripts, inspect `demos/blogger_agent/intent_to_primitive_catalog.md` in my workspace. Based on my requested feature below, assemble the corresponding software primitives (`SessionStateHydrator`, `CycleOscillationDetector`, `ReflexionEngine`, etc.) from `education/` into a clean, decoupled architecture."*
