# RFP response

**Load when:** RFP, RFI, RFQ, requirements matrix, procurement, compliance matrix

## When to load
A procurement document arrived. Map rows before writing prose.

## What the SE must produce
1. One row per requirement: Cisco product/feature, compliance clause, deviation.
2. Flag "can't meet" rows. Do not invent a feature.
3. Link HLD + BoM draft as appendix. Park for human sign-off before submission.
4. Ask at most 3 clarifying questions per turn.

## Multi-vendor notes
If the RFP allows equivalent, state the Cisco option and the incumbent. Do not pretend a Cisco SKU is a drop-in for a named competitor part.

## Never invent SKUs
Requirement-to-SKU maps stay `[UNVERIFIED]` until CCW/partner. RFP submission is a HITL gate.
